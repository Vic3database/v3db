# 文化姓名池数据整理执行计划

## 目标

在独立工作树中补充原版文化姓名池审计，不修改站点页面，不处理肖像。

## 步骤

1. 先写 `scripts/check_culture_names.mjs`，确认报告不存在时按预期失败。
2. 实现 `scripts/audit_culture_names.mjs`，读取 317 个文化定义、九类姓名池和两套姓名本地化，并关联史实角色审计结果。
3. 生成 JSON 与 Markdown，检查空池、重复项、无效条目、本地化缺失和角色文化字段的统计语义。
4. 运行两个审计器及对应检查器，执行 `git diff --check`，检查脚本语法与重复运行稳定性。
5. 在独立分支提交代码和设计记录；生成的 `output/` 文件保持忽略，不把大体积报告加入提交。
