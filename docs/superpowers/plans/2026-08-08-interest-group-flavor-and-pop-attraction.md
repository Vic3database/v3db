# 利益集团风味特质与人群吸引力

## 目标

在利益集团详情页顶部汇总风味名称；将特质按 `−5`、`+5`、`+10` 三个认可度位置展示，并可在同一位置切换基础特质与风味特质；补充人口加入利益集团时的职业与条件；将返回控件改为箭头，并调整详情标题底色。

## 实施顺序

1. 扩展 `scripts/extract_vic3_countries.mjs`，从 `pop_weight` 提取职业、数值、说明和触发条件，并写入利益集团数据。
2. 重新生成临时数据库和当前版本的意识形态数据分块，只同步本功能所需的生成文件。
3. 更新 `site/app/boards.js`、界面语言包和样式，接入风味名称、三槽特质切换与人群吸引力展示。
4. 扩展静态与浏览器检查，覆盖标题、切换控件、人群吸引力、返回箭头和响应式布局。
