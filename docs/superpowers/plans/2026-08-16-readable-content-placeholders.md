# 内容动态文本可读化实施计划

**目标：** 将日志、事件、决议本地化文本中的脚本表达式转换为中文语义标签，并允许悬停查看原表达式。

**实现范围：** 新建共享显示模块，数据库、本地化源文本、搜索原文和原始脚本保持不变。事件标题、说明、风味文本、选项，以及日志和决议的名称、说明使用同一套转换规则。

**验证方式：** 先建立转换器单元契约和三个板块浏览器断言，确认现状失败；随后接入共享模块、三个板块和样式，重建主站的 VC 副本并运行完整内容检查。

## 任务一：共享转换器

- 新建 `scripts/check_content_dynamic_text.mjs`，覆盖当前国家、统治者、角色、法律、利益集团、政党、游说团、文化、地区、公司、商品和未知表达式。
- 新建 `site/app/content-dynamic-text.js`，提供纯文本转换与带原表达式提示的安全 HTML 转换。
- 在 `site/index.html` 中于三个内容板块脚本之前加载共享模块，并在 `site/styles/events.css` 中增加动态文本标签样式。

## 任务二：接入三个板块

- 修改 `site/app/events.js`，转换事件标题、说明、风味文本和选项。
- 修改 `site/app/journals.js`，转换日志名称、说明和日志组名称。
- 修改 `site/app/decisions.js`，转换决议名称、说明和决议组名称。
- 原始脚本继续通过 `escapeHtml` 原样显示。
