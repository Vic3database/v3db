# 文化类标签关系悬停设计

## 目标

将传承组、传承、语言组、语言、传统与文化标签改为专用悬停内容。悬停框直接列出当前条目关联的数据，所有名称完整显示并自动换行。名称采用纯文本，鼠标移入名称时不生成第二层悬停，不提供链接，也不保留原生 `title`。

文化类悬停的关系如下：传承组显示组内全部传承；传承显示采用该传承的全部文化；语言组显示组内全部语言；语言显示采用该语言的全部文化；传统显示采用该传统的全部文化；文化显示以该文化为主流文化的国家、痴迷和禁忌。当前 1.13.9 数据中，前四类的最大列表分别为 26、20、22、19 项；文化的主流文化国家最大列表为 35 项，因此不设置截断数量。

## 数据与渲染

页面继续从 `site/versions/<version>/data-cultures.js` 读取 `cultures`、`cultureTraits` 和 `cultureTraitGroups`。传承组和语言组依据特质组的 `type` 与特质的 `group_key` 查找成员。传承和语言依据文化的 `heritage.key` 或 `language.key` 查找文化。传统依据文化的 `traditions[].key` 查找文化。文化的国家、痴迷和禁忌分别使用文化条目的 `related_countries`、`obsessions`、`taboos`。

`site/app/tag-tooltip-definitions.js` 保存各类关系分区的中文标题与空值文案，便于直接编辑。`site/app/ui.js` 根据概念种类和键生成关系分区；`site/app/components.js` 继续只提供稳定的概念种类、键和分类元数据。通用标签悬停保持现有的定义说明和实体说明后备规则。

分区内容按中文名称排序，名称之间用顿号分隔。没有关联数据时显示定义文件中的空值文案。关系名称以经过转义的纯文本写入悬停框，不生成 `a`、`pill`、`data-concept-*` 或 `title` 属性。悬停框沿用现有定位逻辑；样式允许内容换行，并为过高内容保留滚动空间，保证完整列表仍可查看。

## 验证

先扩展文化悬停契约测试，使其要求定义文件包含分区标题、界面代码根据五类文化特质和文化实体生成关系分区，且关系名称不创建嵌套概念标签。再以 `data-cultures.js` 的已知条目核对关系来源，例如欧洲传承组、拉美移民传承、班图语支、西班牙语和阿法尔文化。

本次不执行浏览器检查，由维护者自行确认页面效果。静态检查应覆盖六类关系的完整数据来源、无嵌套概念标签和无原生 `title`；现有标签悬停、右侧详情布局、意识形态和前端拆分检查也必须通过。
