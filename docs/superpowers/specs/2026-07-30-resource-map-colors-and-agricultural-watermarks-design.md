# 资源地图颜色与农业文字水印设计

## 目标

资源地图不再让全部资源复用同一条黄褐色梯度。每种资源使用稳定的主色，储量仍由同一主色从浅到深表示。农业资源维持统一绿色，以便地图颜色持续表示“农业资源”；具体作物通过战略区域级文字水印识别。

## 资源颜色

地图资源色表覆盖当前 1.13.9 数据中的 27 项资源。煤矿、铁矿、铅矿、硫矿、金矿、渔业码头、捕鲸站、伐木营地、橡胶种植园、油井以及全部 16 项农业资源各有固定的深色终点。地图使用既有的相对储量计算方式，将中性浅色插值至该终点；海域继续使用现有海域颜色，无资源地区继续使用现有浅灰。

金矿场是唯一不在资源筛选栏预设表中的地图资源。它是可发现资源，开采后对应金矿，因此必须与金矿共用金色终点，不增加独立的备用颜色。将来数据遇到未列入色表的资源时，继续使用现有黄褐梯度，保证新数据可显示且不会被误认为已有分类。

农业的 16 项资源统一使用同一条绿色梯度：小麦、黑麦、水稻、玉米、杂谷、畜牧、葡萄、咖啡、茶叶、烟草、鸦片、香蕉、糖料、丝绸、棉花和染料作物。颜色只表达农业资源的储量，作物名由地图控件、提示框和水印表达。

## 农业文字水印

当地图当前资源属于农业资源时，为每一个至少包含一处该资源的陆地战略区域绘制一次低透明度文字水印。文字是当前资源的中文名，例如“小麦农场”或“茶叶种植园”。非农业资源不绘制该类水印。

水印锚点为战略区域全部陆地州地区像素的几何中心，不按当前资源所在地区重新计算。这样文字保持战略区域的居中感；若资源集中在区域边缘、群岛或半岛，水印可以落在该战略区域内没有当前资源的陆地，但不得落到海域。具有分离陆块的战略区域以中心附近的有效陆地像素作为最终落点。没有当前资源的战略区域不显示水印。

水印使用浅色、半透明、略微倾斜的粗体文字，位于地区着色图层上方，并在地区储量数字下方。水印随地图的平移、缩放和横向环绕副本同步绘制。为了避免全图缩小时文字覆盖，绘制前按照可见位置和文字边界检测碰撞；发生碰撞时跳过后续水印。缩放、平移或切换资源后重新计算可见水印，放大后可显示更多。

## 实现与验证

资源色表和“是否农业资源”的判断放在地图模块可复用的位置。资源特征构建函数将根据当前资源取得梯度终点，金矿场映射到金矿终点。地图图层缓存签名保持与当前资源和可见地区集合相关；水印依赖当前资源、地图变换和视口大小，因此不写入底图缓存，而在每次主画布绘制时叠加。

增加静态检查，确认资源色表包含全部当前资源及金矿场到金矿的映射，农业资源共用绿色终点，水印只在农业资源模式启用，战略区域锚点从全部陆地州地区计算，文字使用当前资源中文名，海域不会成为锚点，碰撞水印被跳过且在地图重绘时重新计算。继续运行 JavaScript 语法检查、现有资源与地图检查、差异空白检查；浏览器检查验证一项农业资源在多个战略区域显示水印、非农业资源没有水印、缩放后水印数量变化且地图交互与提示框正常。
