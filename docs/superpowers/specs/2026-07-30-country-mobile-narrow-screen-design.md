# 国家板块窄屏适配设计

## 范围

本轮只调整国家板块在手机竖屏中的查询、筛选、地图与详情阅读流程。文化、地区、公司、意识形态、法律和科技不改变现有行为；已确认的两层文化特质筛选仅作为后续复用方向，不写入本轮运行时代码。

目标视口为 390×844 CSS 像素。紧凑布局由视口长宽比判定：宽度不超过高度的 1.5 倍时使用该布局，宽度大于高度 1.5 倍的横向视口保持现有三栏布局；不再以 820 像素作为上限。

## 列表页

国家列表页顶部使用一行工具栏：条件与关键词共用的搜索框、执行搜索按钮、筛选展开或收起按钮、地图展开或收起按钮。搜索框中的条件显示为带细边框的可删除短标签，每个标签自带删除按钮。关键词输入区位于全部标签之后。

条件与关键词在同一条不可换行的横向滚动区。选中较多条件时，用户可以左右滑动查看或删除早先的标签；输入区获得焦点时滚动到最右端。搜索关键词与全部已选条件共同过滤结果。

筛选默认关闭，地图默认展开。地图位于工具栏和结果列表之间，默认占用上半屏；点击地图按钮后隐藏地图，结果列表填补可用空间。筛选按钮展开一个位于工具栏下方的筛选区，关闭时完全隐藏。

展开筛选区的第一行是可横向滚动的分类按钮：类型、位阶、战略区域、传承、语言、传统。第二部分只显示当前分类的选项，按标签自身宽度从左到右排列并在空间不足时自然换行。

同一分类最多选择一个具体条件。选择新选项会替换该分类原条件；不同分类的条件可以共存，筛选结果取交集。点击已选择的选项也可取消该分类条件。标签默认显示短名称；出现同名条件时，冲突项在名称后用全角括号显示分类。

## 详情与返回

在宽度不超过高度 1.5 倍的视口中，打开国家详情后隐藏国家列表、筛选区和地图，只显示详情文章。详情标题中的返回按钮和浏览器后退都返回此前国家列表，并还原筛选条件、搜索关键词、排序方式、地图和筛选展开状态，以及列表滚动位置。

## 实现边界与验证

新增的窄屏状态与国家筛选条件放入现有运行时状态对象；桌面端仍使用既有左栏筛选控件。国家列表页由现有的哈希路由继续驱动，详情页保持 `#/country/<TAG>`。

新增静态契约检查，覆盖所需的运行时状态、国家分类、搜索标签容器、窄屏断点和详情页隐藏规则。新增浏览器检查使用 390×844 移动视口，验证工具栏位于地图之前、类型选项自然换行、默认地图、筛选开关、同类替换与跨类共存、搜索标签删除、地图收起、详情进入与两种返回方式后的滚动恢复。手工检查通过本地服务器打开国家页并切换浏览器设备模拟即可完成。
