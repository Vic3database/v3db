# 日志、事件与决议全局搜索设计

## 目标与范围

全局搜索增加日志、事件和决议三类结果，覆盖原版 1.13.10、主站 Victorian Century 和独立 Victorian Century 站点。用户可以通过标题、ID 和所属组找到内容并进入现有详情页。搜索框增加“详细搜索”开关；开关默认关闭，状态只在当前页面会话中保存。

默认搜索字段包括中英文标题、内容 ID、日志组名称与 ID、事件组名称与 namespace、决议组名称与 ID。详细搜索在这些字段之外增加说明、风味文本、事件选项、日志目标及结果说明、决议说明、来源文件路径和原始脚本。测试、调试内容继续遵循各内容板块现有的数据收录规则，不由搜索功能另行过滤。

## 数据与搜索流程

构建流程在现有 `search-index.js` 中加入日志、事件和决议的轻量条目。每条记录保留类型、ID、双语标题、双语组名和导航键，不写入说明或原始脚本，以免显著扩大首屏加载文件。

打开全局搜索时仍加载现有搜索所需的数据。首次启用“详细搜索”后，前端从已加载的 `journalEntries`、`contentEvents` 和 `decisions` 生成详细字段缓存；后续输入复用该缓存。关闭开关后，匹配范围立即恢复为轻量字段。切换版本或数据集时清空缓存，防止不同版本的数据混用。

默认字段完全匹配标题时优先级最高，其次为 ID 完全匹配、标题前缀匹配、默认字段包含匹配，最后为详细字段匹配。结果继续使用现有的 120 条上限。命中详细字段时显示匹配位置附近的简短文本；默认字段命中不显示脚本摘录。摘录须经过现有 HTML 转义流程。

## 界面与导航

“详细搜索”开关放在全局搜索输入框下方，与现有旧版本搜索开关使用相同的控件样式。开关需要中英文界面文案，并说明开启后会搜索说明、选项、来源路径和原始脚本。

三类结果分别显示“日志”“事件”“决议”类型名称，正文包括标题、ID 和所属组。点击结果分别进入 `#/journal/<ID>`、`#/event/<ID>` 和 `#/decision/<ID>`，沿用现有详情页，不新增详情组件。键盘上下选择与回车跳转继续使用现有全局搜索交互。

## 验证要求

合同测试需确认三类记录进入原版与 VC 搜索索引，双语标题、ID、组名和导航类型齐全；详细字段没有写入静态轻量索引；搜索结果函数具有开关隔离、缓存和三类导航分支。

浏览器测试需在原版 1.13.10 和独立 Victorian Century 站点验证：默认搜索可通过标题、ID 和组名命中三类内容；关闭详细搜索时，只有说明、选项、来源路径或原始脚本中的词不能命中；开启后可以命中并显示摘录；点击结果进入正确详情。主站 VC 输出与独立站点的数据索引还需通过静态一致性检查。
