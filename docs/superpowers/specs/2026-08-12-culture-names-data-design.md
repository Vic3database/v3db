# 文化姓名池数据整理设计

## 范围

从原版 `game/common/cultures/00_cultures.txt` 读取全部文化定义，整理每个文化实际使用的九类姓名池：普通男性名、普通女性名、贵族男性名、贵族女性名、君主男性名、君主女性名、普通姓氏、贵族姓氏和君主姓氏。姓名保持游戏原始键，并从简体中文与英文姓名本地化文件补充显示文本。

姓名池按原始顺序保存，不展开名与姓的所有组合。空姓名池、重复条目和本地化缺失作为统计与校验结果保留。

## 史实角色关联

复用史实角色审计输出中的角色键、姓名、性别、角色类型、是否出现在开局历史和来源文件。角色文化字段使用 `cu:` 前缀时去掉前缀后关联文化定义；`primary_culture` 保留为角色原始字段，但不归入具体文化。没有文化字段的角色不挂到任何文化下。

## 输出

脚本 `scripts/audit_culture_names.mjs` 生成 `output/culture-names/culture-names.json` 和 `output/culture-names/culture-names.md`。脚本 `scripts/check_culture_names.mjs` 检查文化数量、姓名池字段、姓名条目结构、重复与空池统计、本地化覆盖率，以及史实角色文化键关联。
