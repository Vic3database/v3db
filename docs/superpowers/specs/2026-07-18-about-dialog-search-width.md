# 关于弹窗宽度

## 目标

“关于”弹窗在桌面端与全站搜索使用相同的宽度规则：`min(1080px, 100%)`。现有响应式外边距继续由弹窗遮罩层负责。

## 范围

只调整“关于”弹窗的宽度。“设置”弹窗继续使用现有的 `min(820px, 100%)` 宽度和高度限制。全站搜索的布局、最大高度、内容和交互不作修改。

## 实现与验证

为“关于”弹窗增加独立样式选择器，将其宽度覆写为全站搜索的宽度规则，避免改变共享 `.info-dialog` 对设置弹窗的约束。静态检查将断言该选择器存在且使用 `min(1080px, 100%)`；随后运行关于页面检查、全站搜索检查、脚本语法检查与空白错误检查。
