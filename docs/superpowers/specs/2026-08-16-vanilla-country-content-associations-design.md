# 原版风味内容与国家关联设计

## 范围

原版 1.13.10 复用已经用于 Victorian Century 的主体国家分类器、证据结构、反向索引和前端关联组件。日志、事件和决议均写入 `country_scope`、`country_scope_evidence` 与 `content_kind`；事件的 `event_kind` 与 `content_kind` 保持一致。历史版本 1.13.9 本次不重建。

数据库保留游戏、测试和调试定义，审计文件统计全部定义。站点的日志、事件、决议板块只收录 `content_class: "game"`。原版条目在站点内容块中统一标记来源为 `vanilla`，不会出现 VC 新增或调整标签。

## 构建流程

新增原版国家关联数据库生成器，读取 `database/vic3_1.13.10` 中已经提取的日志、事件和决议，调用共用分类器后回写三份数据文件，并生成独立审计文件。`content-index.json` 登记审计文件和分类说明。

新增原版站点内容生成器，先执行数据库关联生成器和既有事件站点生成器，再生成 `data-content.js`。共享内容块包含游戏日志、游戏事件、游戏决议、日志组和 `contentByCountry`；`data-index.js` 增加 `content` 数据块。既有 `data-events.js` 从数据库中的统一分类字段读取国家范围，停止以旧事件启发式结果作为发布口径。

## 界面与验证

前端继续使用现有的相关国家组件和国家风味内容组件。原版内容详情显示相关国家，国家详情显示可展开的日志、事件和决议区域，并支持双向跳转。原版导航与三栏布局沿用现有日志、事件、决议板块，不增加新的合并板块。

数据合同核对三类正向字段、审计统计、国家标签有效性、正反索引一致性以及事件块与共享内容块分类一致性。浏览器回归覆盖原版国家页到三类内容的跳转、三类内容返回国家页、直接链接和窄屏布局。
