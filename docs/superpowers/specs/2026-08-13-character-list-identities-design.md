# 角色列表身份信息设计

## 范围

仅调整历史角色列表卡片，不改变角色数据、姓名池数据或详情页布局。角色肖像继续跳过。

## 交互与内容

- 中文姓名显示在卡片第一行，英文键在同一行右侧对齐。
- 默认利益集团和初始意识形态在卡片身份行以现有图标和本地化名称显示。
- 身份图标使用现有利益集团、意识形态资源及其辅助函数；缺少资源时保留可访问的占位元素。
- 角色卡片仍由整行按钮打开角色详情，身份信息提供标题和无障碍标签，不引入嵌套交互控件。

## 响应式约束

英文键允许在窄列表中换行，但保持右对齐；身份行可换行，卡片内容不得造成横向溢出。现有独立角色页的列表、详情宽度和移动端替换关系保持不变。

## 验证

浏览器回归检查首条角色记录的英文键、右对齐样式、利益集团图标、意识形态图标和本地化身份名称，同时继续检查角色数量、地图隐藏、详情跳转、特质本地化及宽窄视口布局。
