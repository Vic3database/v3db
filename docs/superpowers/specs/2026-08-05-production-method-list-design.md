# 生产方式分组列表与经济术语修正规格

## 范围

本次只调整中文主站的建筑详情页。生产方式改为接近游戏原界面的分组列表，商品与职业采用游戏图标；商品详情页、英文界面和 Victorian Century 的完整内容扩展不在本次范围内。生产方式的组合结果继续按当前每组所选项计算，保留一层建筑的劳动力、投入商品、产出商品、标准产值和修正汇总。

页面顶部保留一行生产方式图标，每个图标代表一个生产方式组当前选中的生产方式。该行只显示图标，悬停和无障碍标签保留生产方式组名称。点击图标后，只展开该生产方式组；其他组的选项不会与其混排。展开区标题显示组名，例如“基础”“自动化”或“所有权”。

同组内每个生产方式占一行。左侧是生产方式图标和名称，右侧依次排三层信息：第一层只显示商品，投入为红色减号加商品图标与数值，产出为绿色加号加商品图标与数值；第二层只显示劳动力，职业图标后接数量；第三层只在存在内容时显示所需科技、可用条件、无等级修正和有等级修正。当前生产方式只通过整行金色边框辨认，不显示“当前选中”或“当前选择”文字。点击同组另一行后，更新该组选择、顶端图标和下方组合汇总，展开区保持打开。

旧的“生产方式详情”折叠框删除。所有单项生产方式数据都在展开区内直接可见。无投入、无产出、无劳动力或无第三层数据时不以“无”占位；组内每行根据实际内容收紧高度。

## 数据、图标与术语

商品数值从生产方式效果中的 `goods_input_*_add` 和 `goods_output_*_add` 提取，直接按商品键渲染图标、中文名和一层建筑数值，不能复用修正本地化句子。`wood` 是“木材”，`hardwood` 是“硬木”；“软木”没有对应的商品键。商品键和图标直接决定显示名称，避免再次出现“0.25伍德”这类错误文案。

劳动力从 `building_employment_*_add` 提取，使用游戏 `gfx/interface/icons/pops_icons/<职业键>.dds` 转换出的站点资源。职业名称继续使用本地化词条，`clergymen` 统一改为“教士”。生产方式、商品、职业和科技图标均使用游戏原资源；修正与条件保留短文本，避免把无法辨认的纯图标堆叠到第三层。

修正按效果缩放方式分类：`level_scaled` 归入“有等级修正”；其余非商品、非劳动力效果归入“无等级修正”，并保留“按劳动力”或“固定”的说明。所需科技显示科技图标和名称；可用条件存在时与修正同列显示。每个分类都只显示实际存在的数据。

Victorian Century 的“新增”“调整”标签只比较实际展示或计算所用的数据，排除 `source_file`、`source_files`、`patch_directives` 等来源与合并过程字段。对确有差异的建筑、生产方式、商品和名贵商品，生成可读的变更字段清单，并在详情页的 Victoria Century 变更区显示；没有实际差异的条目不显示“调整”标签。

## 实现与验证

前端保留 `selectedProductionMethods` 和 `openProductionMethodGroup` 状态。渲染层改为先输出图标条，再按当前打开的组输出独立列表。生产方式效果分类、商品行、职业行和第三层附加信息拆为小函数，组合汇总继续复用同一份效果分类逻辑。站点资源构建新增职业图标类别，并扩展发布文件校验。

自动校验覆盖：图标条只含图标；一次只存在一个展开组；同组每项具有商品行、劳动力行和可选第三行；选择生产方式后组合结果重算；旧折叠框不存在；`clergymen` 显示“教士”；`hardwood` 显示“硬木”；职业与商品图标文件存在。Victorian Century 校验会验证来源字段和补丁指令不会单独产生“调整”标签，并验证有真实差异的条目带有具体变更说明。浏览器回归检查桌面与窄屏布局，确保不同组不混排、行内图标不溢出、生产方式切换与资源地图入口仍可用。
