# 通用标签提示框布局设计

## 范围

将 `codex/global-tag-tooltips` 分支截至 `c0f2b6bf` 的标签提示框实现纳入当前主分支。除意识形态外，所有带有 `data-concept-key` 的标签和图标标签使用统一提示框。意识形态继续使用现有的图标、法律态度和说明布局。

## 布局与内容

通用提示框的标题行左侧显示中文名和 ID，右侧显示类型。标题行之后显示分隔线；其后按数据可用性显示说明、上下文和文化关联内容；内容与操作提示之间显示第二条分隔线。传承、语言等文化特质及特质组优先显示数据中的具体类型，其余标签优先采用标签提供的类别，缺少类别时采用概念类型名称。

详情能力由链接地址判断，筛选能力由概念搜索数据判断。提示框末行按实际能力显示“左键进入详情页”和“右键进行筛选”；两种能力均不存在时不生成末行和相邻分隔线。右键处理仅对可筛选的标签生效，保证提示文字与交互一致。

文化标签的传承、语言、传统、主要文化国家、关注商品和禁忌商品继续作为内容区的关系段落。普通语义标签沿用已有的显式说明、实体说明和后备说明解析。建筑、商品、国家、地区、公司、法律、利益集团及文化特质使用同一标题与操作提示模板。

## 实现与验证

将文化专用的标题和分隔线渲染函数及样式提取为通用组件，提示框行由一个统一渲染入口生成。合并前置提交后，补充标签提示框静态契约，检查通用标题、两处分隔线、能力驱动的操作提示与意识形态例外；运行 JavaScript 语法检查和现有标签、右栏、意识形态契约。按要求不进行浏览器验证。
