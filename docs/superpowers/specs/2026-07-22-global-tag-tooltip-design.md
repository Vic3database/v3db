# 全站标签悬停说明设计

## 范围与目标

资料库的国家、文化、州地区、战略区域、地理区域、公司、利益集团、意识形态、法律、建筑、商品与特质页面中，列表和详情页的语义标签统一显示大悬停说明。标签包括开局状态、国家类型、国家位阶、文化传承组与传承、语言组与语言、公司类别、资料片、商品状态、区域分组、法律类别以及现有的概念标签。只承担操作功能的按钮、装饰图标和实体徽章不进入本次范围。

现有页面同时存在概念标签与普通标签。概念标签通过 `data-concept-*` 属性进入 `#conceptTooltip`，普通标签由 `tagPill` 直接输出，并可能附带浏览器原生 `title`。两种实现并列时，鼠标会同时触发大悬停与浏览器小提示。改动后的每个语义标签都只能使用页面大悬停；标签触发大悬停时不得保留原生 `title`。

## 结构与数据流

在 `site/app/components.js` 中增加一份标签语义目录。目录以稳定的类别和键值描述标签名称、中文定义、可选的标识符以及适用上下文。国家的开局、殖民国家、公国等状态和位阶在目录中拥有各自的定义；能够从数据实体取得名称、键值或关系的标签继续使用该实体信息，不重复维护名称。目录未收录的标签仍生成大悬停，显示标签名称、通用类别和可用的键值，避免出现空白说明。

通用标签生成器改为输出与概念标签相同的 `data-concept-*` 元数据，并保留现有类别样式与链接行为。现有 `conceptPill`、`tagPill`、分组特质标签、有限引用标签、建筑图标标签和各板块的专用标签生成器都通过这一入口传递语义。大悬停读取目录和实体索引，按“名称、类别或标识符、说明、交互提示”的固定顺序渲染；意识形态现有的富文本大悬停保持专用布局。

生成器在写入概念元数据后不输出 `title`。为避免旧模板或图标标签遗漏，悬停调度层在显示大悬停前清除触发元素的原生 `title`，并保留其值供非悬停辅助信息使用。焦点进入、右键搜索、链接进入详情和离开标签后的隐藏行为沿用当前事件处理，不改变键盘操作和卡片点击逻辑。

## 异常处理与验证

目录查找失败、实体数据缺失或标签为空时，页面不报错。空标签继续不渲染；有标签但没有专用说明时显示通用说明，不写入原生提示。数据中不存在的类别以“概念”作为后备类别，并将原始键值放在大悬停中，便于排查数据导入遗漏。

测试先覆盖目录命中、目录后备、生成器元数据和原生提示抑制四项行为，并在未实现前确认测试失败。实现后运行现有界面契约脚本与新增标签悬停契约脚本，检查所有主要板块的标签生成路径都带有概念元数据，且没有同时输出 `title`。浏览器检查至少覆盖国家的开局、殖民国家与公国标签，以及文化、州地区、公司和意识形态页面各一个标签，确认只出现页面大悬停且说明可读。
