# 国家与地域单击局部更新设计

## 目标和范围

国家与地域板块的左键单击改用局部更新路径。右侧卡片和地图上的左键单击均保留当前地图缩放与位置，只更新选中卡片、地图着色和地址栏中的列表路由；地图单击不再使右侧列表平滑滚动。右箭头和地域地图双击仍进入详情页，筛选、排序、切换板块、切换版本和重置地域焦点仍使用完整渲染。

当前国家与地域选择都会调用 `render()`，使 `renderCountryList()` 或 `renderRegionList()` 重建全部卡片，并在地图重绘后继续调用自动聚焦。默认结果分别约为 750 个国家与 675 个地域。本次只改变选中态的更新方式，不引入列表虚拟化，也不拆分现有地图颜色图层。

## 实现

在 `presentation.js` 中为国家和地域分别建立选择提交函数。它们保存前一选中键，写入现有状态字段并调用 `replaceHash()`，随后调用局部列表更新和地图颜色更新，不调用 `render()`、`focusCountryOnMap()`、`focusStateRegionOnMap()` 或 `scrollIntoView()`。国家地图使用 `renderMap(countryMapStateRegions(selectedCountry))`。地域地图由专用帮助函数按照当前筛选条件重新取得陆地、海域和地理区域的地图来源，再调用 `regionMapStateRegions()` 与 `renderMap()`；这个轻量筛选不生成卡片，保证选中海域时仍遵循现有地图规则。两条路径各只进行一次地图画布绘制。

国家和地域卡片的选中状态由一个局部同步函数维护。该函数只查找前一键和新键对应的 `data-country` 或 `data-state-region` 节点，更新 `aria-current`。国家地图点到当前筛选结果以外的国家时，清空选中态并恢复当前筛选地图，保持现有完整渲染后的最终语义。地域地图点到筛选结果以外的地域时，复用地域卡片模板在列表顶部创建或替换一张 `region-map-selected` 临时卡片；从该临时卡片再次选择或切换到正常列表项时，按现有 `mapSelectedStateRegion` 规则移除它。

国家与地域列表改为由 `countryList` 容器统一处理点击、键盘选择和详情箭头。容器根据 `data-country`、`data-state-region`、`data-country-detail` 和 `data-state-region-detail` 分派行为，避免在完整渲染后为每个卡片重新注册监听器，也使临时地域卡片具备相同行为。其他板块沿用原有监听方式。

现有完整渲染仍保留国家和地域的自动地图聚焦，以免扩大筛选、排序和路由切换的行为范围。局部选中路径跳过该调用，因此连续单击不会改动 `mapRuntime.transform`。修改 `presentation.js` 后更新 `index.html` 中该脚本的版本参数，避免服务器的不可变脚本缓存继续提供旧代码。

## 验证

先更新 `scripts/check_region_map_interaction.mjs` 的断言：地域地图单击仍停留在 `#/region`，不再调用 `scrollIntoView()`，局部选择函数不调用 `render()`，并保留临时地域卡片和详情箭头的契约。扩展国家地图选择检查，要求国家局部选择函数不调用 `render()`，筛选排除对象时清空选中态，国家和地域的完整渲染函数继续负责筛选结果的完整列表生成。

浏览器验证在无筛选、地域筛选和国家筛选三种状态下分别进行。记录连续左键单击前后未选中卡片的节点身份和地图变换参数，确认两者不变；确认目标地图着色、旧新卡片选中态、地域临时卡片、国家筛选排除语义、右箭头详情页和地域双击详情页均符合现有约定。运行相关静态检查、`node --check` 和 `git diff --check`，再比较优化前后连续选择的性能记录。
