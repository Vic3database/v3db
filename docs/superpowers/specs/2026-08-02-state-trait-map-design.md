# 地区特质地图设计

## 范围

在地域板块筛选栏的“地图”分组中新增“地区特质视图”开关。开启后，地图不再显示资源数字，而是在每个地域中心完整显示该地域拥有的全部地区特质图标。现有资源、战略区域和地理区域筛选继续决定地域是否正常显示；不符合当前筛选的地域和其图标均沿用地图已有的灰显状态。

“地区特质视图”与“地形视图”互斥。点击其中一个时切换到对应视图；再次点击已选视图、清除筛选或离开地域板块时恢复默认地图。此次不新增顶部导航、路由、地图模式下拉选项或地区特质筛选器。

## 图标与交互

地区特质使用现有 `site/assets/state-traits/` 中的 PNG 素材，文件名沿用详情卡片的解析规则：优先从数据中的 DDS 图标路径取末段并替换扩展名，缺失路径时由 `state_trait_` 后缀生成文件名。当前 221 个地区特质均可解析至现有 23 个图标文件，无需新增或转换素材。

图标由画布的地图标注层直接绘制。每个地域的图标以地域中心为锚点，按紧凑网格排列，显示全部特质；图标保持与现有地区特质卡片相同的 22 像素屏幕尺寸，地图空间不足时允许重叠，不隐藏、不截断、不以数字合并。图标在缩放、拖动和横向循环地图中跟随地域移动，且不拦截地图指针事件。

地区特质视图的底图使用地域视图的浅色陆地底色与既有海域显示方式，保留地区边界。悬浮提示在地区特质字段中用图标、名称和效果完整列出该地域的特质；单击选中地域、双击进入地区详情、拖动与缩放行为保持现状。

## 验证

新增静态检查，确认筛选栏、运行时元素、互斥切换、地图模式优先级、图标路径解析和画布标注层均已接入。检查使用主站数据验证所有有特质地域均进入地图特征集合，且一个多特质地域保留全部图标引用；同时确认 221 个唯一特质均能映射到实际素材。

浏览器回归覆盖主站与 Victorian Century：开启视图后检查地图模式、开关状态、可见图标、一个多特质地域的完整图标数、资源筛选后的灰显、悬浮提示中的图标和效果，以及单击和双击行为。另在 390 像素宽视口确认地图未产生页面横向溢出，图标保持可绘制并可随缩放、拖动移动。

## 2026-08-03 视觉修订

每个地域的全部地区特质图标固定在同一行，以地域中心为横向中心依次排列，不再使用多行网格。地图图标由 22 像素调整为 30 像素屏幕尺寸，缩放地图时保持该尺寸不变；地域较小或特质较多时继续允许图标互相覆盖及跨越地域边界，不隐藏、不截断、不缩小。

悬浮提示中的地区特质图标同步调整为 30×30 像素，文字继续与图标垂直居中。测试需明确断言单行坐标计算、地图图标 30 像素和悬浮提示图标 30 像素，并复跑主站、Victorian Century 与 390 像素窄屏浏览器回归。
