# 史实角色图片显示设计

## 范围

角色列表继续使用现有三列角色板块，不改变姓名、身份图标和英文键的位置。图片数据中包含当前角色模板键时，在原有状态标签行增加“有史实图片”标签；没有对应记录时不增加占位内容。

角色详情在标题下方、字段表格上方显示史实图片。图片使用维基共享资源缩略图，以 `contain` 方式完整显示，不裁切照片、肖像画或版画。图片下方显示类型、作者、图片日期和许可；缺少的作者或图片日期不渲染空字段。“查看维基共享资源文件”链接指向对应的文件页面，完整文件名保留在链接提示中，许可存在网址时也提供链接。

## 数据与本地化

界面只读取现有的 `byHistoricalCharacterImage` 索引，不修改采集结果。图片记录通过 `character_keys` 与模板键对应。新增界面文字进入简体中文和英文界面词条；图片类型 `photograph`、`painting`、`print` 分别显示为“照片”“肖像画”“版画”。所有外部文本在插入页面前转义，外部链接使用新窗口并设置 `noopener noreferrer`。

## 样式与验证

详情图片区域宽度随详情栏变化，图片最大高度受限，深色背景用于容纳不同长宽比。移动端详情仍替换列表显示，图片宽度不超过详情内容区。契约校验约束图片索引、列表标签、详情图片和本地化调用；浏览器校验选取确有图片的角色，检查标签、图片加载、来源链接、桌面布局和移动端溢出。
