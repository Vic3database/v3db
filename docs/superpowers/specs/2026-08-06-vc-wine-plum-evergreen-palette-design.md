# Victorian Century 酒红紫、哑金与深绿配色设计

## 范围

本次只改 Victorian Century 独立站。主站继续沿用现有配色。因为 Victorian Century 的 `site/vc/` 与 `Victorian Century Database/` 都是本机生成目录，主题源文件放在受版本控制的 `site/victorian-century-theme.css`，由独立站构建脚本复制并在生成页面中加载。

## 颜色层级

页面底色为 `#181216`，常规面板为 `#251d22`，抬升面板为 `#34262f`，边线为 `#6a535d`。标题带和章节分区使用酒红 `#542734`，选中态使用梅紫 `#713748`。哑金 `#b89963` 与浅哑金 `#d8bf88` 只用于描边、标题文字、重点数值和滚动条，避免出现原方案的橙黄感。

深绿 `#1e4b42` 及更深的 `#122c29` 用于独立的黑绿金属控制区、当前导航、可用状态、正向信息和少量功能区。它不与酒红或梅紫做渐变，也不以背景光晕扩散到内容区，不作为通用底色，更不重写地图的国家、资源或地形数据色。建筑与商品页的内容容器固定使用 `#251d22`，覆盖基础样式中旧有的蓝绿色渐变。地图继续按数据语义着色，页面主题只改变地图周边容器和控件。

## 构建与验证

`scripts/build_victorian_century_site.mjs` 在复制基础样式后复制主题文件，并在独立站 HTML 的主样式表后插入主题样式表。构建到临时目标目录后，检查器验证颜色令牌、构建接线和生成结果；随后使用现有独立站检查器与浏览器检查器核对入口、页面渲染和主要路由。
