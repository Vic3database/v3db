# 史实角色资料整理设计

## 目标与边界

本轮只整理 Victoria 3 原版 `release/1.13.9` 的史实角色资料，不制作角色肖像、不复制肖像素材、不增加网页板块，也不修改原版安装目录。权威输入固定为 `D:\SteamLibrary\steamapps\common\Victoria 3\game`。

“史实角色”按角色模板中的顶层 `historical = yes` 判定。每条记录保留模板键和来源文件，并提取姓名、性别、出生日期或年龄、角色身份、文化、宗教、利益集团、意识形态、所属地区、特质、DNA 键及其定义状态。再扫描 `common/history/characters`，记录模板是否被 1836 年开局历史引用以及对应文件。

## 数据输出

生成目录 `output/historical-characters/`，该目录被 Git 忽略。`historical-characters.json` 保存完整结构化报告，包含版本、来源、生成时间、统计数字、DNA 缺失列表、开局历史中无 DNA 列表、无效 DNA 引用列表以及全部角色记录。`historical-characters.md` 面向人工复核，按统计、无 DNA 角色、无 DNA 开局角色和全部角色分节；表格只展示摘要，完整字段以 JSON 为准。

## 解析规则

角色模板和 DNA 定义使用递归文本扫描与花括号深度匹配，不能用跨模板的贪婪正则。模板顶层块只在 `historical = yes` 时进入结果。标量字段按定义块的直接层级读取；`traits` 只读取其直接项目，避免把嵌套脚本中的键误认为特质。DNA 是否有效由 `common/dna_data` 中实际存在的顶层定义决定。开局引用只认角色历史文件中 `template = <模板键>` 的直接值，并保留相对来源文件名。

## 验收

校验器必须使用真实原版目录执行，确认模板键唯一、记录数为 1983、DNA 引用无效数为 0，并检查代表性人物维多利亚女王、俾斯麦、慈禧、明治天皇、林肯的姓名、模板键、DNA 键和历史标记。生成 JSON 后再次读取，确认统计数字与记录数量一致；Markdown 与 JSON 同步生成；`git diff --check` 无错误。
