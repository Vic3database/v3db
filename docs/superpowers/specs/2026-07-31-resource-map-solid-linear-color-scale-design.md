# 资源地图实心线性色阶设计

## 目标与范围

资源地图以颜色深浅表示相对储量，以地图数字显示准确数值。选中单项资源后，储量为 1 的州地区使用该资源的淡色端，储量最高的州地区使用该资源既有的标准色，中间储量按线性比例取色。资源区域、无资源陆地和筛选范围外的陆地均完全不透明，纸质底图纹理不会改变陆地资源颜色。

本轮只调整 `resource` 和 `resourceSelection` 两种地图模式，以及 Victorian Century 生成站中的同一套文件。国家、文化、公司、战略区域和地区特质地图继续保留现有的羊皮纸底图、透明度和颜色逻辑。地图数字、边界、提示框、资源筛选与工具栏中的资源上下文栏不改动。

## 绘制规则

资源地图沿用纸质画布底色与 `flatmap_votp.png`。海洋和未映射像素露出纸色纹理；陆地资源层的透明度固定为 `255`，因此纸张纹理不会透过任何陆地区域。

无资源陆地改用冷灰 `#e9edeb`，筛选范围外的陆地继续使用既有的 muted 冷灰，但同样以完全不透明的方式绘制。这样铁矿、煤矿与其他深色资源周围不会残留暖黄色，也能与海洋区分。

单项资源的渐变比例改为 `value / maxValue`，移除平方根转换。矿产、渔业、林业、橡胶和石油补充各自的淡色端；标准色沿用当前资源色。铁矿固定为淡蓝 `#cde0eb` 至蓝灰 `#557b91`。农业资源继续沿用已确定的作物专属淡色端和标准色。金矿场仍映射到金矿色阶。

多项资源同时筛选时，地图继续显示州地区的合计储量和数字。由于合计值不对应某一种资源，使用一组冷蓝灰的组合色阶，按合计储量线性变化；不借用任何单项资源的颜色。单项资源切换、资源上下文栏和数值语义保持原有行为。

## 验证

静态检查覆盖资源模式的透明度为 `255`、线性色阶不再调用平方根、27 类资源都有可解析的淡色端与标准色、铁矿淡色端为 `#cde0eb`，以及资源模式继续绘制纸张底图。检查同时确认无资源资源地图陆地使用冷灰，金矿场别名仍继承金矿色阶。

浏览器检查以铁矿和小麦农场为样本。在资源层写入画布时记录像素 alpha，断言陆地像素只使用完全不透明的 `255`，海洋保持透明以露出浅蓝底色。铁矿图层不得出现黄色起始色，最低储量地区为淡蓝、高储量地区为蓝灰；小麦仍从浅金色线性过渡到金色。检查保留资源图标、中文名称、资料库版本、数值标签和无文字水印的既有断言，并在主站和 Victorian Century 生成站各运行一次。

完成后运行资源颜色静态检查、地区地图交互检查、国家地图选择检查、脚本语法检查和 `git diff --check`。重新生成 Victorian Century 站点后，核对两套 `map.js` 的 SHA-256 一致，并以浏览器截图复核铁矿图中纸色海域已恢复、黄色无资源陆地未恢复。
