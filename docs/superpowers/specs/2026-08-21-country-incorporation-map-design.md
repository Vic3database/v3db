# 国家整合年数地图设计

## 目标

在国家板块增加“整合年数”地图模式。选中一个国家后，该模式可用；地图覆盖全部有地图数据的全球陆地地区，并按该国主流文化与地区本土文化的关系显示整合所需基础年数。海域保持中性色，不参与计算。其他板块和国家板块现有的“开局归属”地图保持原行为。

## 判定规则

每个地区取其本土文化与选中国家全部主流文化比较后的最短基础年数。比较顺序固定为：

1. 2年（文化本土）：地区本土文化本身是国家的主流文化。
2. 5年（同传承、同语言）：本土文化与任一主流文化具有相同的具体传承特质和具体语言特质。
3. 10年（同传承或同语言）：本土文化与任一主流文化具有相同的具体传承特质或具体语言特质。
4. 15年（同传承组或同语言组）：前面没有匹配，但本土文化与任一主流文化具有相同的传承组或语言组。
5. 25年（无共同传承组或语言组）：没有上述匹配，或地区没有本土文化。

文化的传统特质不参与判定。整合速度修正、行政能力和其他运行时修正不在此地图中计算；地图显示的是游戏定义中的基础年数。

## 界面与数据流

- 国家板块地图工具栏增加“整合年数”按钮；没有选中国家时按钮禁用。按钮只在国家板块显示。
- 选中或清除国家时，模式状态与当前选择保持一致；清除国家后自动回到“开局归属”模式。
- 整合年数模式渲染全部 `stateRegions`，不使用当前国家领土范围，也不受国家列表筛选影响。
- 地图特征标题显示地区名称、基础年数和匹配关系；地图提示保留地区、战略区域、本土文化，并加入整合年数与匹配档位。
- 地图下方增加五档图例，文字固定为上述中文文案；海域不放入年数图例。
- 使用单向、易读的色阶：2年采用深绿色，5年采用绿色，10年采用金色，15年采用橙色，25年采用红色；海域采用现有海色。颜色只在整合年数模式生效。

## 实现边界

- 复用现有地图画布、缓存、提示和图例结构，新增独立的 `countryIncorporation` 地图模式与计算函数。
- 复用现有文化数据中的 `heritage.key`、`language.key`、`heritage.group_key`、`language.group_key` 和地区的 `homeland_cultures`。
- 不修改文化板块的筛选语义，不把传统特质加入整合年数计算，不修改其他板块的地图模式。
- 中英文界面均提供按钮、图例和提示文案。

## 验证

- 单元式静态测试覆盖五档优先级、多个本土文化取最短年数、无本土文化取25年、传统特质不影响结果。
- 契约测试确认模式只在国家板块注册，按钮和图例存在，中英文文案齐全，其他板块没有引用国家整合状态。
- 浏览器测试确认未选国家时按钮不可用；选中国家后可切换到全球整合年数地图；清除选择后恢复普通国家地图；筛选国家列表不会裁剪整合地图。
