# 公司板块建筑筛选排除项设计

## 范围

公司板块的建筑筛选栏不显示金矿场 `building_gold_field` 和自给建筑地图入口 `subsistence_buildings`。金矿 `building_gold_mine` 保留。普通公司列表、公司建筑组合器及公司板块内复用该筛选栏的界面遵循同一规则。

地区板块继续显示金矿场和自给建筑，自给建筑地图、资源地图及建筑资料不改动。产业组合求解器使用独立建筑目录，本轮不修改其数据。

## 实现

在 `visibleResourceFilterGroups()` 为公司视图构造资源筛选组时，复制现有分组并排除上述两个筛选键。保留原始 `resourceFilterGroups`，避免影响地区板块和地图功能。筛选状态同步使用公司视图过滤后的列表，因此被排除项不会以隐藏状态残留。

## 验证

先在公司建筑组合器浏览器检查中断言两项不存在且金矿仍存在，再验证普通公司路由使用相同结果。地区路由需继续包含金矿场和自给建筑，以证明修改没有扩大范围。现有公司组合器与地区自给建筑检查继续通过。
