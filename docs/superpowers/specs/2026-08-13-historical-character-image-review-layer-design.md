# 史实角色图片人工复核层设计

## 目标与范围

在自动采集报告与前端图片数据之间增加版本化人工复核层。自动规则继续负责人物匹配、许可检查、排除群像及生成图等不合格内容；人工复核只处理自动规则已经确认人物关系和许可、但无法判断图片类型的候选。第一条正式记录批准 `albert_einstein_template` 使用费迪南德·施穆策 1921 年拍摄的照片。

复核文件保存角色模板键、维基数据编号、维基共享资源文件名、决定、图片类型、复核日期和理由。角色键集合、人物编号和文件名必须同时与本轮采集结果一致。批准记录不能绕过人物对应证据、许可和排除规则；拒绝记录会使对应候选退出自动选择。未被采集器使用的记录视为数据过期并使构建失败。

## 数据流与验证

采集器读取 `scripts/data/historical-character-image-reviews.json`，在自动选图前应用拒绝记录，在自动选图后允许合格的批准记录指定候选及类型。确认人物记录增加确认方式和人工复核摘要，统计信息分别记录自动确认与人工确认人数。完整报告仍是唯一的前端数据构建输入，前端无需读取复核文件。

单元校验覆盖复核文件结构、批准记录精确匹配、拒绝候选排除及安全规则不可绕过。首条样本先让爱因斯坦从待复核集进入确认集；随后首批审核再批准十名人物，并拒绝艾米·卡迈克尔的群像。重建后确认集应为 401 人、404 个角色模板，其中人工复核 11 人；待复核集应为 595 人。角色列表应出现“有史实图片”标签，详情应显示爱因斯坦的 1921 年照片。
