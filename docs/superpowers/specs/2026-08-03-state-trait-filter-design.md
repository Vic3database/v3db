# 地区特质筛选设计

## 范围与交互

在地域板块的筛选栏中新增“地区特质”筛选类别，展开后提供“所有、河流海港、土壤地貌、自然资源、殖民环境、MAPI”六个选项。现有独立的“地区特质视图”按钮不再作为入口；地区特质视图完全由这组筛选项驱动。

初始状态不选中任何地区特质选项，地图保持普通地域视图。选中“所有”后进入地区特质视图并展示全部地区特质；选中任一具体分类后进入带分类筛选的地区特质视图。再次取消最后一个选项时退出该视图，恢复普通地域地图。

“所有”与五个具体分类互斥。选择“所有”会清除已经选择的具体分类；选择任一具体分类会取消“所有”。五个具体分类允许多选，彼此按“或”匹配：一个特质只要符合任一所选分类便属于匹配结果。MAPI 与其余分类平级，不再作为独立的“且”条件。

地形视图与地区特质筛选互斥。开启地形视图时清空地区特质选项；选择任一地区特质选项时关闭地形视图。已有资源、战略区域、地理区域等筛选继续生效，并与地区特质筛选共同约束地域列表和地图灰显结果。

## 分类与数据流

分类依据地区特质数据中的结构化字段判定，不依据图标文件名。Victorian Century 存在不同特质复用同一图标的情况，使用图标归类会产生错误结果。

分类规则如下：

- “河流海港”命中 `river` 或 `port` 类别。
- “土壤地貌”命中 `agriculture` 或 `terrain_climate` 类别。
- “自然资源”命中 `resource` 类别。
- “殖民环境”命中含有殖民所需科技或特质消除科技的特质，即 `required_techs_for_colonization` 或 `disabling_technologies` 非空。
- “MAPI”命中 `has_mapi` 标记为真的特质。

同一特质可以归入多个分类。例如河流带来的农业修正可以同时属于“河流海港”和“土壤地貌”，资源型地形可以同时属于“土壤地貌”和“自然资源”。多选时只记录一次特质，不重复绘制图标，也不在地区列表中重复地域。

分类函数接收一个特质并返回其命中的筛选键集合，供筛选栏、地域列表和地图绘制共同使用。原版与 Victorian Century 使用同一函数；后续新增特质只要保留现有结构化字段即可自动归类。缺少分类信息且不符合殖民环境或 MAPI 条件的特质只在“所有”中出现。缺少图标文件不会改变筛选和地域列表结果，只跳过该图像的地图绘制。

## 地图、列表与悬停提示

选中“所有”时，地域列表保留所有含地区特质且符合其他现有筛选条件的地域，地图按完整地区特质视图显示全部图标。

选中具体分类后，地区列表只保留至少含有一个匹配特质并且符合其他现有筛选条件的地域。地图继续绘制所有地域，以便保留空间背景：含有匹配特质且符合其他筛选条件的地域维持正常底色，匹配图标使用完整亮度；同一地域中的未匹配图标使用 0.18 不透明度。完全没有匹配特质或不符合其他现有筛选条件的地域沿用现有灰显底色及图标不透明度。无匹配结果时，列表显示现有空状态，地图上的地域全部灰显。

每个地域的全部图标继续以地域中心为横向中心固定排成一行，保持屏幕尺寸，不换行、不截断、不合并为数字。地域较小或特质较多时允许图标彼此重叠并跨越地域边界。地图图标从现有 30 像素调整为 38 像素；绘制时继续抵消地图缩放，使其在不同缩放等级下维持 38 像素的屏幕尺寸。

悬停提示保留该地域的完整特质内容，不因分类筛选删除条目；其中的地区特质图标同步调整为 38×38 像素。单击选中地域、双击进入地域详情、地图拖动、缩放和横向循环行为保持现状。

## 状态与异常处理

地区特质筛选状态应使用稳定的筛选键保存，不保存本地化标签。数据集或语言切换后重新对当前数据执行分类，选项语义保持一致。与其他筛选条件相同，离开地域板块时保留已经选择的地区特质筛选键，但不在其他板块应用地区特质地图模式；返回地域板块后，只要仍有地区特质选项处于选中状态，就重新进入地区特质视图。使用全局重置按钮时清空这组筛选键并恢复普通地图。

图标加载失败时不阻断其他图标、地域底色或列表渲染。分类字段缺失时按未命中具体分类处理。不存在地区特质的地域在“所有”和具体分类下均不进入列表，并在地图上灰显。所有判断均处理空数组与缺失字段，避免原版和 Victorian Century 数据结构的可选字段差异造成运行时错误。

## 验证

静态检查覆盖筛选定义、六个选项、互斥切换、五个具体分类的“或”逻辑、分类函数的结构化字段映射、地图模式切换、地域列表约束、图标去重、38 像素地图尺寸和 38×38 像素悬停提示尺寸。分类测试应包含同时命中两个分类和三个分类的特质，并确认同一图标只绘制一次。

浏览器回归同时覆盖原版与 Victorian Century。验证“所有”完整展示、各具体分类、多个分类联合选择、MAPI 与其他分类联合选择、清空后退出视图、地形视图互斥、现有筛选共同生效、无匹配地域灰显、同一地域内匹配与未匹配图标的亮度差异，以及地区列表与地图结果一致。另在窄屏下检查筛选栏可操作、页面无新增横向溢出，图标仍固定为单行并允许重叠。
