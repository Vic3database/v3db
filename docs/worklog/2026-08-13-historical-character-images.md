# 2026-08-13 史实角色图片资料

本轮为 1.13.9 的史实角色建立可追溯图片资料，只接受能够明确对应人物本人的照片、肖像画和版画。来源使用维基数据人物条目与维基共享资源文件页；每条确认记录保留维基数据编号、文件页、原图与缩略图地址、图片类型、作者、年代、许可和人物对应证据。雕塑、纪念碑、签名、纹章、货币、群像、现代生成图和面部重建图均排除。

1,983 个角色模板全部进入确认、待复核、未匹配或明确排除状态。确认集含 390 人，覆盖 393 个模板，其中照片 215 幅、肖像画 135 幅、版画 40 幅。331 人通过完整英文名与出生年匹配，45 人通过保守的多词别名与出生年匹配，14 人通过完整英文名与 1836 年开局年龄对应的出生年范围匹配；另有 1 个无日期的卡尔·马克思模板并入已确认人物。6 个 `spooky_templates.txt` 中的虚构角色明确排除。其余记录保留在本地报告的待复核与未匹配部分，不进入前端数据。

新增 `site/versions/1.13.9/data-character-images.js`，角色数据块会同时加载图片数组和统计信息，运行时按角色模板键建立图片索引。当前没有改动角色列表和详情页的视觉布局。采集和校验脚本位于 `scripts/collect_historical_character_images.mjs`、`scripts/collect_historical_character_image_name_candidates.mjs`、`scripts/lib/historical_character_images.mjs` 及对应的检查脚本；完整研究报告与网络缓存位于忽略目录 `output/historical-character-images/`。

最终校验包括图片规则、完整报告覆盖、前端数据块、别名候选、角色板块契约、数据分块和 JavaScript 语法检查。45 名别名人物中有 37 幅完成缩略图目视检查，14 名开局年龄人物中有 11 幅完成目视检查；可读取的画面均为对应人物的单人照片或单人肖像。其余 11 幅因缩略图代理不支持对应路径或文件而未下载，仍依据人物条目直接图片声明、文件说明和许可信息保留。

角色界面现已使用图片索引。列表对索引命中的模板增加“有史实图片”标签，原有姓名、身份图标和英文键排列保持不变；详情在字段表格前显示维基共享资源缩略图，并列出图片类型、作者、图片日期和许可，文件标题链接到对应的共享资源页面。图片采用完整显示方式，不裁切原图；没有图片记录的角色不显示标签或图片占位。

界面校验使用 `ada_lovelace_template` 检查列表标签、详情图片加载与共享资源链接，同时检查无匹配角色不出现标签。浏览器测试覆盖 2048×1024 桌面三栏布局和 390×844 移动端详情，确认列表与详情不重叠，图片区域不产生横向溢出。图片数据校验仍为 390 人、393 个角色模板。
