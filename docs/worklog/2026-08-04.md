# 2026-08-04：多语言合并至 main

## 合并内容

在隔离工作树中以 `main` 的建筑、商品版本为基础合并 `codex/multilingual-architecture`。冲突涉及成就契约、数据提取器、运行时、首页、样式入口和 1.13.9 数据索引；处理后保留建筑与商品板块，并接入简体中文、英语运行时、语言菜单、URL 参数、语言存储、按板块加载的语言包和双语搜索索引。

建筑与商品数据改用结构数据和独立语言包。建筑页、商品页、生产方式详情、当前生产方式组合、商品属性、生产与消费建筑、人口需求、文化痴迷、文化与宗教禁忌、名贵商品和相关公司均支持简体中文与英语。资源类建筑仍可打开资源地图并自动选择对应资源。重新生成 1.13.9 数据后，主站包含 101 个建筑、53 种商品、72 种名贵商品、197 个生产方式组和 436 种生产方式。
