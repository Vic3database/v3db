# 整合时间计算器侧栏修正

## 修改内容

文化检索输入框改为按 Enter 提交，输入中文时不会触发重绘。传承、语言和传统筛选分成三个独立折叠区，各自保留开合状态。侧栏底部新增五档整合年数图例，颜色与地图使用的 2、5、10、15、25 年规则一致。

新增 2026-08-28 公告：“新增整合时间计算器，可以自定义选文化然后计算整合时间，并且做了改变文化本土相关的适配。”公告数据由 `announcements.md` 重新生成。

## 验证

计算器浏览器回归覆盖原版、Victorian Century 独立站和 `site/vc`：中文输入后按 Enter 检索、拼音检索、三个筛选组折叠、图例、地图着色与文化本土效果均通过。发布包、公告、首页和 Victorian Century 独立站静态检查通过。
