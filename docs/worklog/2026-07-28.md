# 2026-07-28：地域地图焦点与初始视图

地域板块选中陆地地域时，地图仅保留该地域为可见陆地，并以拉普拉塔绿 `#00cc66` 显示；其他陆地由既有灰显逻辑处理。未选中地域时，地图继续显示战略区域配色。实现位于 `site/app/map.js`，回归条件位于 `scripts/check_region_map_interaction.mjs`。

地图工具栏的圆形箭头按钮在地域板块中现为“重置地域焦点和地图位置”。按钮会清空 `selectedStateRegion` 和 `mapSelectedStateRegion`，重新绘制战略区域底图，再恢复地图位置；国家等其他板块仍保留原有的仅重置地图位置行为。按钮辅助标签随板块更新。

静态验证通过：`node scripts/check_region_map_interaction.mjs`、`node --check site/app/ui.js`、`node --check site/app/map.js`、`node scripts/check_country_map_selection.mjs` 与 `git diff --check`。页面验证使用 `http://127.0.0.1:8891/site/index.html#/region`：初始渲染了 675 张地域卡片；单击 `STATE_SVEALAND` 后仅一张卡片处于选中状态且画布内容改变；单击圆形箭头后选中卡片数回到 0，画布内容再次改变。页面没有运行时错误；切至国家板块后按钮标签为“重置地图位置”。
