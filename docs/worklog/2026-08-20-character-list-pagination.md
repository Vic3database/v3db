# 2026-08-20 史实角色列表分页

史实角色板块现在按筛选、搜索和排序后的完整结果分页，每页最多显示 100 人。列表顶部和底部都提供页码、上一页、下一页和结果范围说明；分页按钮使用现有中英文界面本地化，并带有当前页、禁用态和无障碍标签。筛选、搜索、排序及清除筛选会回到第一页，打开角色详情后返回列表会保留当前页。

角色板块继续使用独立的三栏布局，分页样式允许窄屏换行，不改变地图板块的布局。分页状态在运行时初始化和数据集重置时同步清除。测试覆盖 1,983 个史实角色、20 页分页、翻页、筛选重置、详情返回、角色图片标签、名称池和移动端详情布局。

本轮验证使用 `node scripts/check_character_board_contract.mjs` 和 `node scripts/check_character_board_browser.mjs`，浏览器测试以无头 Chrome 执行；两项均通过。提交前另行执行 JavaScript 语法检查和 `git diff --check`。
