# 2026-09-14 科技主页与双视图导航重做

## 方案

科技主页 `#/technology` 只负责选择查看方式。生产、军事、社会三个类别各提供“查看列表”和“打开科技树”两个入口，列表路由为 `#/technology/list/<category>`，科技树路由为 `#/technology/tree/<category>`。现有 `#/technology/<key>` 详情链接继续保留。

列表按时代分组，支持名称或效果搜索、时代筛选和 Victorian Century 变更筛选，卡片直接显示主要持续效果。科技树保留节点关系、拖拽、缩放和类别切换。列表和科技树进入详情后共用同一个详情渲染器，详情分为持续效果、研究完成效果、前置科技、后续科技和关联内容；研究完成脚本显示条件、作用对象、结果数量摘要，并保留原始脚本折叠区。

- 科技详情增加持续效果和研究完成效果独立区块。
- 详情返回按钮按来源返回列表或科技树。
