# 首页工具入口

## 修改内容

首页在五个资料分类之前增加独立的“工具”区域。整合时长计算器、产业组合求解器和公司建筑组合器分别直达 `#/culture/incorporation`、`#/company/solver` 和 `#/company/composer`，原有文化板块与公司板块入口继续保留。

工具卡片使用 Lucide 图标、名称、说明和右箭头。桌面宽屏采用三列，较窄视口改为单列。整合时长计算器始终显示；求解器和组合器沿用现有资料库可用性规则，只在原版 1.13.11 与 Victorian Century 中显示，旧版原版资料库不显示不可用入口。

## 验证范围

首页静态契约检查工具区结构、三条路线、可用性规则和响应式样式。浏览器检查覆盖主站、Victorian Century 独立站和 `site/vc`，验证三张工具卡片的顺序、Lucide 图标、直达路线、旧版资料库入口数量、英语界面和 442 像素窄屏。
