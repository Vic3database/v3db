# 文化板块整合时长计算器

## 目标

在文化板块提供按国家预载、按文化标签自由组合的整合时长计算器，取代国家详情路径直接进入情景地图的功能，同时保留国家板块基础整合年数地图。

## 已完成修改

使用唯一入口 `#/culture/incorporation`。直接进入时不绑定国家，候选区提供当前资料库的文化；从国家详情点击入口时，只把该国主流文化和已审计候选预载到侧栏，地址仍保持唯一入口。地图保持主视区，文化选择放在左侧栏；候选文化只修改待计算集合，点击“开始计算”后才应用颜色。页面不再显示独立的“整合结果”板块，地图提示承担结果查看。新增“添加其他文化”筛选区，按传承组、传承、语言组、语言和传统筛选后加入文化；“可能涉及的文化”保留为少量高优先级候选，不再放搜索框。筛选方式默认折叠，搜索框位于筛选区顶部，筛选结果用独立标题和分隔线显示；输入搜索或选择条件后保留展开状态。

本轮重做工具归属和标题栏：计算器标题采用公司详情页同款标题行，返回按钮固定在左侧并使用 Lucide 箭头图标；计算器只在文化板块显示，求解器和组合器入口及详情面板在离开公司板块时统一隐藏并清空，避免工具内容残留到其他板块。

计算器地图工具栏隐藏列表折叠和国家整合年数按钮；重置视图按钮右侧显示当前选择的文化，选择或移除文化时同步更新。

新增文化本土变化数据，覆盖原版 26 项和 VC 44 项事件、日志、决议记录。固定地域效果可勾选，启动计算后叠加到地图本土文化；动态范围效果只展示条件说明，不改变地图。美国昭昭天命、俄勒冈、夏威夷、奥地利伦巴第等固定地域效果已纳入检查。

移除了旧的国家路径情景按钮、情景运行时状态、情景地图上下文和情景专用浏览器脚本。国家板块的基础整合年数按钮仍保留，继续使用国家默认主流文化。主站、Victorian Century 独立站和 `site/vc` 已同步计算器前端。

## 未解决问题

计算器展示的是用户选择文化后的静态地图规则，不模拟游戏时间推进、速度修正、法律效果或实际条件满足状态。顶栏缓存检查仍有既有基线问题时，单独记录，不修改无关缓存链。
