# 2026-08-16 日志、事件、决议板块

Victorian Century 独立站继续使用原版 1.13.10 作为基础，内容数据为日志 857 条、事件 2946 条、决议 102 条。合并阶段为 VC 独有条目写入 `vc_change_kind: "added"`，为同 ID 且脚本或本地化有差异的条目写入 `vc_change_kind: "adjusted"`；当前事件为 VC 新增 682 条、VC 调整 12 条，另有 14 条同 ID 覆盖内容与原版相同，未标为调整。日志为 VC 新增 438 条、VC 调整 37 条，决议为 VC 独有 42 条。日志解析已识别 VC 的 `REPLACE_OR_CREATE:ID = { ... }` 前缀；旧构建漏掉了 38 个这类定义，其中 37 个应覆盖原版、1 个为 VC 新增，同时漏掉 2 个对应日志组。

前端将日志、事件、决议拆成 `#/journal`、`#/event`、`#/decision` 三个板块，保留左侧筛选、中间列表和右侧详情布局。日志按日志组名称与日志 ID 排序，提供来源、VC 变更、搜索和日志组导航；详情包含说明、显示条件、开启条件、完成与失败条件、完成／失败／超时效果、触发事件、来源文件和原始脚本。决议按来源文件与决议 ID 分组，提供来源筛选、搜索和分组导航；详情包含说明、显示条件、执行条件、执行效果、人工智能权重、触发事件、来源文件和原始脚本。旧的 `#/content/journal`、`#/content/event`、`#/content/decision` 链接会跳转到相应独立板块，独立站导航和首页不再展示旧的合并入口。

随后完成桌面与窄屏视觉验收。发现日志、决议页面未套用内容板块的三栏定位规则，已在 `site/styles/events.css` 中统一隐藏地图、接入左筛选—中列表—右详情布局，并为窄屏改为纵向排列；组导航保持普通内容流，由左栏统一滚动。日志、决议浏览器检查增加桌面列宽、地图隐藏和窄屏堆叠断言。视觉截图保存在 `screenshots/content-boards-visual/`，最终的日志、事件、决议板块均通过截图复核。

本地化检查随后补充到合并数据和浏览器验证中。VC 条目在自身中文词条为空或缺少正式原版词条时，会回退到原版 1.13.10 的中英文本；由日志实际引用但没有组定义的日志组，也会按正式组词条生成导航数据。事件列表优先读取合并数据内嵌的本地化，条件式标题会并列显示其正式标题分支。371 个事件组和 38 个决议组均增加了可读中文名称，同时保留命名空间或来源文件供核对。VC 中有 26 个德国风味事件缺少正文和选项文本，其中 21 个连标题也为空；这些条目的脚本没有可据以整理的实际效果，界面保留事件 ID 并将空白选项标为“未命名选项”。人工智能专用决议的空白说明则依据执行条件和效果补写了中文摘要。

旧的“日志、事件、决议”合并板块随后下线。主站、VC 独立站和 `site/vc` 发布副本已移除该板块的导航项、切换选项、筛选结构、首页入口与 `app/content.js` 渲染脚本；`content` 数据块继续作为三个独立板块共用的数据载体。`#/content/journal`、`#/content/event`、`#/content/decision` 旧地址仍会转到对应独立板块。事件 `acw_events.9` 的官方标题“星杠旗”增加所指对象说明，资料库显示为“星杠旗（美利坚联盟国国旗）／给我的自由”。

日志、事件、决议的标题、说明、风味文本和选项随后接入共用的动态文本转换。`[ROOT.GetCountry.GetRuler.GetPrimaryRoleTitle]` 等脚本表达式在中文界面显示为“（统治者头衔）”，以适应君主、总统等不同政体；国家、人物、继承人、法律、利益集团、政党、游说团、地区、城市、文化、公司和商品等常见对象也使用相应的可读占位词。占位词悬停时显示完整原表达式，搜索字段、条件与效果脚本、来源数据均保留原文。独立站重建后通过共享转换静态检查、日志与决议专门浏览器检查、1.13.10 事件浏览器检查、三个板块合并检查和独立站文件检查。

风味内容与国家的双向关联随后接入构建流程。主体国家只从日志的未激活显示条件与开启条件、事件触发条件、决议显示条件与执行条件中读取；明确的当前主体调用和 `c:TAG` 国家作用域会沿触发事件、开启日志关系传播，随机国家、任意国家和临时作用域不传播。事件命名空间、日志组和决议来源文件只在直接证据覆盖率达到 80%、涉及国家不超过 8 个时补足组内无直接条件的内容，另保留 5 个已有源码位置的稳定事件组范围。构建产物为每条记录写入 `country_scope`、`country_scope_evidence` 和 `content_kind`，事件同时更新 `event_kind`；`content-country-association-audit.json` 保存组统计、关系、无效目标和原版 1.13.10 旧分类差异。

当前合并数据中有 356 条风味日志、853 条风味事件和 52 条风味决议，反向索引涉及 94 个可解析国家。证据共 2028 条，其中直接条件 506 条、组证据 82 条、关系继承 1440 条，当前没有人工校正条目。解析出 2479 条内容关系，包括当前主体 2183 条、明确国家 128 条、未知国家作用域 168 条；未知作用域不会传播。国家标签未解析数为 0，组冲突为 0；5 条关系指向合并数据库中不存在的日志 ID，已留在审计文件中，没有写入反向索引。原版 1.13.10 事件块含 2239 条事件，其中旧规则判定 836 条风味事件；新规则只保留主体国家，因此有 696 条事件的国家范围变化，差异逐条记录在审计文件中。

内容详情在标题和来源信息之后显示可点击的相关国家、国旗与标签，通用内容不生成空白区域。国家详情在基础信息之后显示“风味内容”，顶部列出日志、事件和决议数量，三个分类按组名和 ID 排序并默认收起；条目保留标题、ID、组名以及 VC 新增或调整标签。浏览器检查覆盖国家与三类内容之间的往返跳转，以及 442×844 窄屏下的纵向排列、无横向溢出和单一详情滚动区域。主站源、`Victorian Century Database` 和 `site/vc` 的关联组件与样式哈希一致，两个 VC 副本的 `data-content.js` 哈希一致。
