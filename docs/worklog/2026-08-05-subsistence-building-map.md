# 2026-08-05 自给建筑地图

## 实现范围

资源筛选区新增“自给建筑”入口。入口不缩小地域列表，切换后在同一张州区地图上按自给建筑类型着色：自给农场为 `#c8893f`，自给水稻农场为 `#4c9f70`，自给牧场为 `#8b6f47`，自给果园为 `#b5688b`，自给渔村为 `#4b87b6`。地图下方图例显示五类建筑的本地化名称，海域维持原有海色且没有数字标签。

每个陆地区域的地图中心显示 `arable_land` 数值，数值为零时同样显示。悬浮提示显示战略区域、自给建筑、耕地和地区特质；单击仍在地域视图中选中区域，双击进入地域详情。拖拽、滚轮缩放与再次点击取消选择沿用原有地图行为。

后续修订将资源筛选入口改为自给农职业图标 `assets/pops/peasants.webp`，不在按钮中显示“自给建筑”文字。图例改为逐项列出自给农场、自给水稻农场、自给牧场、自给果园和自给渔村，并说明同类建筑中颜色越深代表耕地上限越高。每一种建筑使用自身的可耕地上限范围计算浅色至深色的渐变，因此五类建筑都能在图上呈现可辨识的明暗差异；地图中心的数字保留，用于跨类型直接读取具体上限。

## 验证

`scripts/check_subsistence_building_map.mjs`、`scripts/check_resource_map_colors.mjs` 和 `scripts/check_region_map_interaction.mjs` 均已通过。主站 Chrome 回归确认 781 个州区图形完整、675 个陆地区域的耕地数字与数据一致、海域没有数字、五种颜色和五项图例正确；390 像素宽视口中地图面板与图例宽度均为 366 像素，没有横向溢出。

渐变修订的 Chrome 回归额外确认入口图标已实际加载，五项图例文字完整，五类建筑各自最低和最高可耕地样本均使用不同的颜色，且颜色计算与定义的渐变端点一致。

图例首次实现只验证了节点渲染与未隐藏，遗漏了实际叠放位置。桌面地图使用绝对定位的全尺寸画布，普通文档流中的图例被画布覆盖，因此页面中看不到。图例已改用与地形图例相同的绝对定位，位于地图下方；地图视口为其预留 88 像素。浏览器回归要求桌面和 390 像素宽度下图例顶部均在地图视口底部之后，并在地图像素层加载完成后截取实际可见画面。

该隔离工作区未包含 Victorian Century 的生成站点目录，因此本次未对其发布产物运行浏览器回归；主站源码变更会在后续生成 Victorian Century 独立站时一并带入。
