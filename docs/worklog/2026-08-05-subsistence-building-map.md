# 2026-08-05 自给建筑地图

## 实现范围

资源筛选区新增“自给建筑”入口。入口不缩小地域列表，切换后在同一张州区地图上按自给建筑类型着色：自给农场为 `#c8893f`，自给水稻农场为 `#4c9f70`，自给牧场为 `#8b6f47`，自给果园为 `#b5688b`，自给渔村为 `#4b87b6`。地图下方图例显示五类建筑的本地化名称，海域维持原有海色且没有数字标签。

每个陆地区域的地图中心显示 `arable_land` 数值，数值为零时同样显示。悬浮提示显示战略区域、自给建筑、耕地和地区特质；单击仍在地域视图中选中区域，双击进入地域详情。拖拽、滚轮缩放与再次点击取消选择沿用原有地图行为。
