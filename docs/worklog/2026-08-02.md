# 2026-08-02：英文地域资源标签修正

英文地域页选择资源后，地图对象下拉框和资源上下文仍会显示中文资源名。原因是筛选按钮通过 `entityText()` 读取当前语言的建筑名称，选中资源后的地图分支却回退到 `resourceFilterGroups` 内的中文 `label`。

新增 `resourceFilterLabel()`，由资源、农业资源或公司建筑的内部键查找建筑条目，再按当前语言、英语、内部键的既定顺序取名。筛选按钮、选中资源标题和地图要素共用该函数。`map.js` 与 `components.js` 的缓存版本更新为 `20260802-resource-localization1`。资源地图静态检查中的旧缓存断言同步到当前入口文件。

浏览器回归先确认原代码在选择煤矿后报告“煤矿”，再验证修正结果。主站和 Victorian Century 均逐个选择地域页全部 27 个资源选项，并检查英语正文；1440×1000 与 390×844 视口中的煤矿标题均为 `Coal Mines`。历史版本夹具新增地域资源用例。两站原有八个板块和全量详情审计继续通过，主站覆盖 2,950 条详情，Victorian Century 覆盖 3,032 条详情。截图只用于本地复核，不纳入提交。

## 英文详情格式与修正数值

法律效果的英文名称、数值和摘要字段含有相同文本，详情页因而把原始效果说明重复显示为粗体数值。公司繁荣修正也使用英文摘要字段，只显示名称而缺少结构化数值。意识形态说明保留了 `#lore`、`#italic`、`#!` 等游戏格式标记。部分公司没有控股类别，但英文类别消息错误地指向公司名，导致列表标签和详情类别重复公司名。

新增共用的游戏本地化文本清理函数，处理概念引用、变量引用、图标、空格和样式标记；能映射到建筑、商品、利益集团、意识形态、法律或科技条目的引用优先使用当前语言名称。法律效果和公司繁荣修正改为从结构化 `value` 取值，并按提取器既有规则显示普通数值或百分比。空公司类别不再读取错误的英文消息，详情显示 `None`，列表不生成该标签。公司繁荣效果标签允许在窄屏换行，390 像素视口内可完整显示 `+15%` 与 `+5%`。

浏览器回归先记录法律效果重复原始标记的失败结果，再验证修正。主站和 Victorian Century 均检查简体中文与英语切换、八个内容板块、1440×1000 与 390×844 视口，并遍历全量英文详情；审计额外检查全部法律效果、意识形态说明和公司繁荣修正是否残留游戏格式标记。主站覆盖 2,950 条详情，Victorian Century 覆盖 3,032 条详情。历史版本夹具验证君主制四项数值、伊巴德派伊玛目意识形态说明、Akers Mek 公司空类别和两项繁荣数值。`check_company_technology_requirements.mjs` 因本工作树没有被忽略的 `database/victorian_century/companies.json` 数据文件而未运行，其余相关静态检查通过。

## 地区特质英文修正数值

地区详情卡片已经使用结构化修正值，地区特质标签的悬浮说明仍读取 `modifierSummary` 本地化字段。英文数据中的该字段会回退为特质名称，因此奥得河悬浮说明只显示 `Oder River`，没有 `Infrastructure +15`。悬浮说明现改为遍历特质的 `modifiers`，并与详情卡片共用 `modifierSummaryLabel()`；名称继续按当前语言读取，数值从结构化 `value` 取得。

测试先记录奥得河标签说明只有名称的失败结果，再验证说明与详情卡片的全部效果逐项一致。主站奥得河显示 `Infrastructure +15`；Victorian Century 版本显示 `Infrastructure +30`、`Market Access Price Impact +2.5%` 和 `Home defense +2.5%`。主站与 Victorian Century 的完整英文浏览器回归均通过，覆盖八个板块、1440×1000 和 390×844 视口；主站审计 2,950 条详情，Victorian Century 审计 3,032 条详情。历史版本夹具在两种视口验证 `Infrastructure +15`。地区静态契约、语言结构、Victorian Century 构建与独立站检查均通过。
