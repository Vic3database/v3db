# 整合时间计算器左栏溢出修复

## 目标

修复整合时间计算器在窄左栏中显示文化本土变化卡片时出现的水平滚动条。

## 完成内容

- 提高计算器文化本土变化标签的布局规则优先级，覆盖通用筛选标签的横向 `flex` 规则。
- 为事件键、标题和说明增加断行规则，长键不会再撑宽卡片或左栏。
- 更新主站和独立版样式缓存版本，并让浏览器回归检查覆盖三套站点的卡片布局与溢出情况。

## 验证

- 计算器静态契约、国家整合契约、发布包、独立版、首页和公告检查通过。
- 原版、独立 Victorian Century、`site/vc` 的计算器浏览器检查通过。
- 公司产业求解器和公司产业组合器浏览器检查通过。
