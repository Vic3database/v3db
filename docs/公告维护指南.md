# 首页公告维护指南

首页右侧的公告栏由仓库根目录的 `announcements.md` 生成。只需编辑这一份文件；不要直接修改 `site/announcement-data.js`，因为构建时会覆盖该文件。

## 公告格式

文件第一行必须是 `# 站内公告`。每条公告以 `## YYYY-MM-DD｜标题` 开始，日期、标题和正文都不能留空。日期使用四位年份、两位月份和两位日期，标题与日期之间使用全角竖线 `｜`，不要使用半角竖线 `|`。

```markdown
# 站内公告

## 2026-07-26｜近期更新

统一了悬浮标签的样式。

## 2026-07-20｜资料补充

补充了部分地区的资源与公司条件。

第二段正文可以用一个空行分开。
```

公告按日期从新到旧显示。多条公告日期相同时，首页保持文件中的先后顺序。正文中的单次换行会显示为换行，空行会形成段落间距。需要新增公告时，在文件中加入一个新的二级标题和正文；需要修改或删除公告时，直接修改或删除对应的完整段落。

## 生成、检查与查看

编辑完成后，在仓库根目录运行以下命令：

```powershell
node scripts/build_announcements_data.mjs
node scripts/check_announcements.mjs
node scripts/check_publish_bundle.mjs
```

第一条命令将 `announcements.md` 写入 `site/announcement-data.js`。第二条命令检查格式、日期排序和首页加载位置。第三条命令确认发布目录中的公告数据与源文件完全一致；若提示 `announcement data is stale`，重新运行第一条命令。

需要在本地查看首页时，运行：

```powershell
node scripts/serve_site.mjs site 8876
```

然后在浏览器打开 `http://127.0.0.1:8876/#/home`。三项检查通过后，上传更新后的 `site` 目录，服务器上的首页公告栏会随之更新。

格式错误时，构建会停止并指出问题所在的行。常见原因包括缺少文件首行标题、二级标题没有日期或标题、日期和标题之间使用了错误的分隔符，以及标题后没有正文。
